# Valuation Checklist — Sanity Checks + Quality Gates

每次做完 valuation，**逐項對**，有一項過唔到就返去改。

---

## A. 數學 / Reconciliation Checks

- [ ] **FCFF Top-down ≈ Bottom-up**（差異 < 5%）
- [ ] **Terminal Value = 40-60% of EV**（> 70% → forecast period 太短）
- [ ] **終期 ROI → WACC**（growth 唔再創造價值）
- [ ] **EPV ≤ DCF value**（EPV > DCF 代表 growth 係 value-destroying，查返 ROI vs WACC）
- [ ] **Multiples 估值 within 25% of DCF**
- [ ] **Reverse DCF implied g ≤ 名義 GDP**（>5.3% 即係市場 overvalue growth）
- [ ] **Interest coverage > 2x** throughout forecast period
- [ ] **Effective tax rate stable, 15-30%**
- [ ] **Historical NWC < 0 → project NWC = 0**（保守）
- [ ] **用 diluted shares**（含 stock options）

---

## B. Phase 6：6-Question Investment Quality Gate

**全部 YES 先建議 BUY。** 有一個 "NO" 或 "UNSURE" → 唔建議買。

- [ ] 1. Investment thesis 清晰明確？點解市場錯價？
- [ ] 2. 兩句話講到個 business model？
- [ ] 3. 明白 competitive moat 點防 competition erode profitability？可唔可以一邊 grow 一邊保持 profitability？moat 有冇夠闊？
- [ ] 4. 對 valuation model + inputs 有信心？assumptions 合理？margin of safety > 20-30%？
- [ ] 5. 願意 hold 5+ 年？Moat 係咪 durable？
- [ ] 6. Exit plan 清晰？咩條件下賣？

---

## C. Red Flags Screen

**有一個都要 flag 畀 Boris。**

- [ ] **Fads & Bubbles**：產品「hot」但無 durable moat（e.g. Crocs 由 $6B 跌到 < $1B）
- [ ] **Serial Acquirers**：Revenue growth 主要靠 M&A，債務堆積（e.g. Valeant）
- [ ] **Financial Shenanigans**：revenue 太早 recognize、expense 延遲、bogus revenue
- [ ] **Obsolete Business**：被新技術顛覆（Kodak、Blockbuster、BlackBerry）
- [ ] **Value Traps**：表面平但 fundamentals 惡化（大 assets + 盈利下跌）
- [ ] **Excessive Leverage**：D/E > 3x 或 interest coverage < 2x
- [ ] **Negative Free Cash Flow** 而且無改善路徑
- [ ] **Management Red Flags**：高層頻繁變動、大量賣股、aggressive accounting

---

## D. Behavioral Bias Audit（自我檢查）

做完 valuation，問自己：

- [ ] **Anchoring**：我有冇被 52-week high / 分析師 target price 拉住？→ 解方：多方法 cross-validate
- [ ] **Confirmation Bias**：我有冇主動搵 disconfirming evidence？→ 解方：寫低最強 bear case
- [ ] **Overconfidence**：我嘅 sensitivity range 係咪太窄？→ 解方：WACC ±2%、g ±1%
- [ ] **Loss Aversion**：我喺 rationalize 現有 position 定係做 fresh analysis？
- [ ] **Recency Bias**：我有冇 overweight 最近 1-2 季？→ 解方：用 5-10 年平均
- [ ] **Herd Mentality**：我嘅 thesis 係咪只係 echo 市場共識？

---

## E. 私營公司額外 checks（Wazup / Deptai 客戶）

- [ ] 有冇 **illiquidity discount**？（通常 20-30%）
- [ ] 有冇 **small-cap premium**？（market cap < $2B → +3-4.7% cost of equity）
- [ ] Beta 係咪用 **peer-derived unlever/re-lever**？（冇市場 beta）
- [ ] Key person risk 有冇 discount？
- [ ] Customer concentration（top 1 / top 5 客戶 % revenue）
- [ ] 估值**畀範圍**，唔好畀單一數字

---

## F. 輸出前最後 sanity check

- [ ] 答案用 **繁體中文廣東話口語**
- [ ] 跟 **Boris decisions.md 標準格式**（選項 A/B + 建議）
- [ ] 有 **三層解釋**（係咩 / 影響 / 類比）
- [ ] 有 **課程引用**（邊個 lecture / 邊個 reference case）
- [ ] 有 **monitoring triggers**（幾時要重新 review）
- [ ] **唔扮專家**：flag 晒假設同 limitation
