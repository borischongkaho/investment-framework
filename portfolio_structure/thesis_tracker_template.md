## How To Use

1. Each earnings: update scorecard (Original / Current / Trend) + Update Log.
2. Each major news: add disconfirming evidence if negative; re-rate conviction.
3. Quarterly: full review — pillar trends, conviction re-rate, portfolio health.
4. Trend turns Concerning on ≥ 2 pillars → re-validate full thesis (possible trim/exit).
5. Stop-loss trigger fires → execute exit per pre-commit, log reason.
